================================================================================
                    STUDYSHELF - SRC/DATA/ FOLDER STRUCTURE
================================================================================

Every category has its own individual folder:
- src/data/8th/
- src/data/9th/
- src/data/10th/
- src/data/11th-commerce/
- src/data/11th-science/
- src/data/12th-commerce/
- src/data/12th-science/
- src/data/novels/

Inside each folder:
1. `index.js`: Contains the book list and metadata for that category.
2. Put your `.pdf` files directly in here (or in the root `data/` folder)!

When the student clicks "Download Book", StudyShelf finds your PDF file
and downloads it immediately to their computer.
================================================================================
